# Homex POS real-products assets

Các file ảnh trong thư mục này được frontend gọi bằng đường dẫn:

/assets/real-products/<ten-file>.jpg

Quan trọng: giữ nguyên tên file để logic map ảnh mẫu hoạt động ổn định.
Nếu muốn dùng ảnh chụp thật 100%, thay ảnh hiện tại bằng ảnh thật cùng tên file.
Không cần sửa code nếu tên file giữ nguyên.
